Mr.R Coding — نظام تسجيل حسابات آمن (نسخة أولية)

المتطلبات:
- تثبيت Node.js إصدار LTS على الحاسبة.
- اتصال إنترنت أول مرة لتنزيل المكتبات.

التشغيل على Windows:
1) فك ضغط mr-r-coding-auth.zip.
2) افتح المجلد.
3) انسخ .env.example وسمِّ النسخة .env.
4) افتح .env وعدّل:
   SESSION_SECRET إلى نص عشوائي طويل (32 حرفاً أو أكثر).
   ADMIN_USERNAME إلى اسم المشرف الذي تريده.
   ADMIN_PASSWORD إلى كلمة مرور مشرف قوية وفريدة (12 حرفاً أو أكثر).
5) افتح Terminal داخل المجلد وشغّل:
   npm install
   npm start
6) افتح Chrome واكتب:
   http://localhost:3000

مهم:
- هذا تطبيق محلي على حاسبتك. لا يصبح رابطاً عاماً بمجرد تشغيله.
- لوحة المشرف تعرض أسماء الحسابات وتواريخ التسجيل فقط.
- كلمات المرور لا تُعرض؛ تُخزّن كـ bcrypt hash للتحقق من الدخول.
- لا تطلب من الناس كلمات مرور Google أو Roblox أو أي حساب آخر.
- لا ترفع ملف .env أو ملفات قاعدة البيانات إلى GitHub.
- قبل النشر العام، انشره على استضافة تدعم Node.js وHTTPS، واستخدم أسراراً قوية في إعدادات الاستضافة، وفعّل نسخاً احتياطية آمنة. لا تستخدم بيانات حقيقية قبل مراجعة إعدادات الأمان والخصوصية.
- إذا غيّرت ADMIN_PASSWORD بعد إنشاء حساب المشرف، لن تتغير كلمة مروره تلقائياً؛ غيّرها عبر آلية إدارة آمنة قبل النشر.
